# Какая стратегия встроена в бота и почему

По итогам всех проверок ([research-strategies.md](research-strategies.md),
[intraday-strategies.md](intraday-strategies.md), [volatile-pairs.md](volatile-pairs.md)) в боте
оставлена одна стратегия — **дневной тренд «лонг или кэш»** (time-series momentum, только лонг,
спот Bybit). Всё остальное из бота удалено.

## Итоги проверки всех стратегий

| Стратегия | Где проверялась | Результат вне выборки после издержек | В боте |
|---|---|---|---|
| **Дневной тренд «лонг или кэш» (TSMOM)** | дневные свечи 2018–2026, 8–10 топовых монет; 12 альткоинов 2023–2026 | Sharpe 0.89–0.94 против 0.51 у удержания BTC, просадка −28…−31% против −67% | **да** |
| BTC выше 200-дневной средней | то же | Sharpe 0.97, просадка −32% (только BTC) | как фильтр `btc_filter`, выключен |
| Ансамбль тренд + возврат к среднему + пробой с «уверенностью» (прежняя стратегия бота) | 1h, месяц и год 2025–2026 | около нуля после комиссий, фильтр тренда не помог | удалена |
| TSMOM лонг/шорт, кросс-секционный моментум, разворот | дневные, 2022–2026 | Sharpe от −3.0 до +0.2 | удалены |
| ML: Ridge, LightGBM, нейросеть (MLP) | дневные, walk-forward | качество прогноза ≈ 0 (IC ≤ 0.02), после комиссий в минусе | удалены |
| Скальпинг, SMC (FVG, order blocks, снятие ликвидности), пробои, VWAP, сезонность | 1m–1h, 19 монет, 2023–2026 | ни одна из 211 конфигураций не повторила отбор; лучшие ±0.05R, t < 1.6 | удалены |

Отдельно о **SMC Fair Value Gap**: в первой версии исследования он выглядел лучшим (+0.1R на сделку),
но это был артефакт симулятора, заглядывавшего в будущее при нескольких висящих лимитках. Ошибку
поймал бэктест самого бота при встраивании; после исправления преимущество исчезло
(подробно — [intraday-strategies.md](intraday-strategies.md)).

## Правила стратегии

Каждый день по закрытию дневной свечи (00:00 UTC) для каждой монеты:

1. **Сигнал тренда** — среднее знаков доходности за 20, 60 и 120 дней; отрицательная часть
   обрезается. Все три горизонта растут → сигнал 1; два из трёх → (1 + 1 − 1) / 3 = ⅓; один из
   трёх или ни одного → 0, то есть монета продаётся и деньги остаются в USDT.
2. **Доля в портфеле** = сигнал / √(число монет) × 25% / годовая волатильность монеты за 30 дней
   (множитель не больше 5). Сумма долей не больше 100% капитала — спот без плеча.
3. **Раз в неделю** (по умолчанию в понедельник, по закрытию воскресной свечи) бот приводит портфель
   к целевым долям рыночными ордерами: сначала продажи, потом покупки на освободившиеся USDT.
   Изменения меньше 1% капитала не торгуются; выход из монеты (доля 0) — всегда целиком.
4. **Стоп-лоссов нет**: монета продаётся, когда по ней пропадает тренд. Защита от обвала — выход
   в кэш по сигналу и маленькие доли волатильных монет.

Код: `backend/app/strategy/trend.py`. Тест `tests/test_trend.py` проверяет, что доли бота совпадают
с исследовательским кодом до 1e-12, а сигналы не заглядывают в будущее.

## Что показала проверка

8 монет спота Bybit (BTC, ETH, SOL, XRP, DOGE, ADA, TRX, BCH), комиссия 0.1% + проскальзывание
0.05% на сторону. Отбор — 2018–2021, проверка — 2022-01 → 2026-09.

| | Sharpe 2018–21 | Sharpe 2022–26 [95% ДИ] | Доходность 2022–26, % в год | Макс. просадка 2022–26 |
|---|---|---|---|---|
| Исследование (векторный бэктест) | 1.77 | 0.89 [−0.15; 1.87] | 22.5 | −28.0% |
| **Бэктест самого бота** (ребалансировка по понедельникам) | 1.65 | **0.90** | **23.3** | **−23.9%** |
| С фильтром BTC > 200-дневной средней | 1.68 | 1.10 [0.10; 2.06] | 28.6 | −24.2% |
| Удержание BTC | 0.80 | 0.51 [−0.45; 1.43] | 14.1 | −66.9% |

Бэктест бота за 2018–2026: 271 владение монетой, прибыльных 37%, profit factor 2.6 — типичная
картина тренда: много мелких выходов с небольшим убытком и редкие длинные тренды, которые дают
основной результат.

Фильтр BTC улучшил результат в 2022–26, но был хуже в периоде отбора 2018–21, а по правилу,
заданному заранее, выбирался вариант с лучшим Sharpe в отборе. Поэтому фильтр доступен в настройках,
но выключен.

## Честные оговорки

* **Доверительный интервал Sharpe начинается около нуля.** За 4.7 года вне выборки статистически
  доказать преимущество нельзя; уверенно можно говорить о вдвое меньшей просадке, чем у удержания.
* **В медвежьем рынке стратегия теряет**, только меньше рынка: на волатильных альткоинах в 2025–26
  −10% в год против −62% у корзины.
* **Ошибка выжившего:** монеты выбраны среди доживших до 2026 года. На паре BTC+ETH без «выживших»
  альткоинов преимущество сохраняется (Sharpe 0.77 против 0.37 у удержания).
* **Исполнение по цене закрытия дня** — приближение: реальные ордера исполняются в первые минуты после
  00:00 UTC с проскальзыванием (заложено 0.05%).

## Настройки риска

| Профиль | Целевая волатильность | Что меняется |
|---|---|---|
| Консервативный | 15% | меньшие доли монет, больше кэша |
| **Умеренный (по умолчанию)** | **25%** | проверенная конфигурация |
| Агрессивный | 40% | большие доли, при сильных трендах — до 100% в монетах |
| Свой | 5–100% | задаётся вручную |

Дополнительно: предел доли одной монеты (`max_weight_pct`) и остановка при просадке
(`max_drawdown_stop_pct`: бот продаёт всё в USDT и ждёт ручного возобновления; по умолчанию выключена,
в проверке не использовалась).

## Как запускать

Сначала paper-режим на несколько недель: он торгует на настоящих ценах Bybit без денег. Первый
расчёт после запуска сразу собирает портфель, дальше — раз в неделю. Бэктест на своих данных:

    cd backend
    uv run python -m app.market.backfill --symbols BTCUSDT ETHUSDT SOLUSDT --days 1500
    uv run python -m app.backtest.cli --symbols BTCUSDT ETHUSDT SOLUSDT
